# ThoughtHealer Website

Official website for ThoughtHealer - A comprehensive mental health platform providing professional support and resources.

## Features

- Responsive design for all devices
- Modern UI with dark/light mode toggle
- Mental health resource cards
- Professional team showcase
- Contact and appointment booking

## Technologies Used

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (Alpine.js)
- Various animations and libraries (GSAP, AOS, Three.js)

## Live Website

Visit us at: [www.thoughthealer.org](https://www.thoughthealer.org)

## Local Development

1. Clone this repository
2. Open `index.html` in your browser
3. All dependencies are loaded via CDN
